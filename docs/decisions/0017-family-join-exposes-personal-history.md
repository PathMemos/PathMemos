# 0017 加入家庭即反向暴露个人全部历史日记已接受

日期：2026-09-29｜状态：已接受

## 背景

ADR-0010/0012 已登记邀请链接「长期有效、无撤销」与 owner 整家合并的钓鱼风险，但只覆盖了被合并方（owner 一侧）。同一机制存在此前未留痕的对称后果：**普通成员打开链接即加入（无确认步），其加入前的全部个人历史日记（文字/位置/图片）随即进入新家庭共享时间轴，对最多 5 个既有成员可见**——对一个隐私敏感的日记产品，这是加入者一侧的显著暴露面，此前无任何决策留痕。

精确语义（代码事实，勿写成「数据迁移」）：diaries/diary_entries 无 family_id，家庭时间轴是按「当前成员集合」实时聚合的视图；加入即视图纳入、退出/被移除即视图收回（`leaveToPersonalTx` 仅迁移封面，条目数据原地不动）。因此暴露是**可撤回的**（退出即收回），但**成员在期内的既有查看/导出副本不可追回**。

## 决策

**接受该风险，不增加加入前确认/共享范围预览**。理由：

- 「加入即共享全部历史」是家庭功能的核心前提：时间轴的价值正在于共见，加入前筛选历史会使功能失去意义（与 owner 合并场景同构）。
- 产品为熟人小家庭场景（上限 6 人），链接在家庭私域流转（ADR-0010/0012 同一理由）。
- 加入前弹确认/预览属过度防御，破坏「扫码即用」体验（ADR-0012 同判）。

## 后果

- 加入者应知悉：加入即共享本人全部历史，退出/被移除后共享视图即收回（无数据迁移），但在期内的既有查看/导出副本不可追回。
- 图片的收回仅对聚合视图成立：URL 级访问不随退出失效（ARCHITECTURE-INVARIANTS I8，知道 URL 即可访问），期内获知的图片 URL 在条目删除/注销清理前持续有效。
- 人工验收（07 F4）验证加入后历史可见、退出后视图收回，不做防护断言。
